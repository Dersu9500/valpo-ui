# valpo-ui

Imágenes de la interfaz de 7 Days to Die para el servidor **7 Valpo**.
El mod del servidor las carga desde aquí, así que los jugadores no tienen que descargar nada.

| Archivo | Uso |
|---|---|
| `logo.png` | Logo de Valpo (600×261) |
| `zombi_salta.png`, `zombi_bloque.png`, `zombi_piedra.png` | Zombis de Valpo (240 px de alto) |
| `zombi_*_mini.png` | Los mismos, en pequeño (120 px), junto a los títulos |
| `dersu_dados.png`, `dersu_dados_mini.png` | Firma «cortesía de Dersu» (dados, fondo transparente) |
| `dersu_dados_oro.png`, `dersu_dados_oro_mini.png` | Firma «Better UI by Dersu»: dados de tres oros con puntos blancos (la que se usa desde el 2-11-2026) |
| `zombi_percepcion/fuerza/fortaleza/agilidad/intelecto.png` (+ `_mini`) | Zombis por atributo, en la pantalla de habilidades |
| `zombi_mochila.png` (+ `_mini`) | Zombi abriendo la mochila, en el inventario |
